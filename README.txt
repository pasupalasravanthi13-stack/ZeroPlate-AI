ZERO PLATE AI MVP

1. Open this folder in VS Code.
2. Open Terminal.
3. Run: pip install -r requirements.txt
4. Run: python app.py
5. Open the Flask address shown in the terminal (usually http://127.0.0.1:5000).

Demo flow: enter attendance/consumption -> Predict Demand -> see recommendation -> Dashboard.

The ML training data is generated demo data. Do not present demo predictions as validated real-world results.
